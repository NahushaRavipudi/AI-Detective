# AI Detective - RAG Based Evidence Analysis System

## Overview

AI Detective is a Retrieval-Augmented Generation (RAG) based web application developed during a RAG workshop. The application allows users to upload evidence documents and ask questions related to the uploaded content. By retrieving relevant information from the documents and using AI to generate responses, the system provides accurate and context-aware answers.

This project demonstrates the practical implementation of document retrieval, embeddings, vector search, and Large Language Models (LLMs) in a real-world scenario.

## Features

* Upload evidence documents
* Analyze uploaded content
* Ask questions about the evidence
* AI-powered answer generation
* Context-aware responses using RAG
* Simple and user-friendly interface

## Technologies Used

* Python
* Streamlit
* Retrieval-Augmented Generation (RAG)
* Embeddings
* Vector Database
* Large Language Models (LLMs)

## How It Works

1. Upload an evidence document.
2. The document is processed and converted into embeddings.
3. Relevant information is retrieved based on the user's query.
4. The AI model generates an answer using the retrieved context.
5. The response is displayed to the user.

## Use Case

Imagine you are investigating a case and have multiple evidence documents. Instead of manually searching through the files, AI Detective helps you quickly find relevant information and answers questions based on the uploaded evidence.
